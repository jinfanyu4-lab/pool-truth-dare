# 开球！真心话大冒险

为郁金帆、邵文浩、罗洁、吴仙凤设计的四人台球聚会小游戏。

## 玩法

1. 从两种两两组队方案中选择一组（不提供罗洁、吴仙凤同组的方案）。
2. 每局结束后手动选择输掉的队伍。
3. 选择“从题库抽取”或“临场发挥”。
4. 败方两人分别独立抽取类型：大冒险概率 80%，真心话概率 20%，因此可能两人都抽到大冒险。
5. 选择“从题库抽取”时系统自动出题；选择“临场发挥”时先抽类型，再由现场玩家出题。
6. 每次落败都会重新独立抽取，不再固定一人大冒险、一人真心话，也不再自动对调。
7. 可以随时换题、清空战报或更换组队。

## 本地打开

这是一个无构建依赖的静态网站。直接打开 `index.html`，或在目录中启动任意静态服务器即可。

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## GitHub Pages

仓库发布后，在 **Settings → Pages** 中选择 `Deploy from a branch`，再选择 `main` 分支和根目录 `/` 即可上线。
